# 英语笔记本（纯净笔记）

纯前端、无需后端。一本按日期分页的电子笔记本：每天一页、可左右翻页，
页面直接书写（加粗 / 斜体 / 下划线 / 删除线 / 列表 / 标题），自动保存到浏览器本地。

## 怎么用

- **写字**：点击纸页任意位置直接输入
- **翻页**：顶部 ‹ › 翻前一天/后一天；点中间日期回到今天；手机上可左右滑动翻页
- **格式**：封面下方工具栏
- **备份**：右上角「⋯」→ 导出 Word 文档(.doc) / 导出备份(.json)
- **迁移**：新设备「⋯」→ 导入备份(.json)，按日期合并

## 本地预览

```bash
cd english-notebook
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 部署

整个文件夹上传到任意静态托管（GitHub Pages / Netlify / Vercel / Cloudflare Pages）即可。

- **Windows（Chrome/Edge）**：打开网址 → 地址栏「安装」→ 安装成桌面应用
- **iOS（Safari）**：打开网址 → 分享 → 添加到主屏幕，之后可全屏离线使用

> 建议使用 https，iOS 的离线缓存和「添加到主屏幕」才完整生效。

## 注意

数据只存在**当前设备当前浏览器**，换设备前先「导出备份(.json)」，再在新设备「导入」。
